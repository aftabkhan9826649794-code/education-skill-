# WINGS GLOBAL - Digital Art & Education Platform

## Implemented Hubs
- [x] Home Page Hub - Navigation to all sections, greeting, voice nav
- [x] AirWrite Hub - Gesture air-writing (pinch/palm) + mouse/touch
- [x] New Creation Hub - Voice/text → AI coloring page → Interactive canvas
- [x] Exam Hub - 3 quizzes (Colors, Shapes, Animals) with scoring
- [x] Voice Command - Web Speech API navigation from home
- [x] Accessibility Hub - Font size, high contrast, text-to-speech

## Tech: React SPA, FastAPI, MongoDB, MediaPipe, OpenAI GPT Image 1, Web Speech API
